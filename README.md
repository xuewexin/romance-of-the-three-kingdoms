# 《乱世残卷：建安魔障》 (Three Kingdoms: The Jian'an Demon)

> 基于《杀戮尖塔》（Slay the Spire）核心架构与深度数值体系打造的本格三国水墨风卡牌构筑 Roguelike（DBG）游戏。

---

## 📖 故事背景

光和七年，九鼎崩解，天命失序。古今名将之执念与上古煞气交织沉沦，九州化作无尽的死局轮回。
天公将军引符水化尸兵，西凉铁骑焚洛阳驻凶关，赤壁冥河锁链翻滚幽冥鬼火。
破局者手握残卷军令，执三尺青锋，踏破四幕魔障，逆转岁月长河！

---

## ⚔️ 核心特色

### 1. 三大独创流派英雄
* **关羽【武圣】**
  * **机制**：武势（Strength）与刀势（Blade Stance）叠层，单卡爆发与连招循环。
  * **代表牌**：青龙斩、拖刀计、义薄云天、武圣神威。
* **诸葛亮【卧龙】**
  * **机制**：天机八卦奇阵。掌控「火·烈焰」、「水·重雾」、「雷·天罚」、「风·狂岚」四大阵眼槽位，通过生成、常驻生效与终结激发带来极高策略上限。
  * **代表牌**：天灯祈星、八阵图、借东风、七星续命、九天引雷。
* **甘宁【锦帆游侠】**
  * **机制**：双刀水战、狂暴连击与弃牌追击收益。
  * **代表牌**：劫营突袭、锦帆铃响、百骑破魏、嗜血连环。

### 2. 深度确定性战斗引擎
* **双端动作队列（Double-ended ActionQueueManager）**：完整还原《杀戮尖塔》的 `addToBottom` / `addToTop` 机制，保障回合阶段、死后触发、打断反击的绝对确定性时序。
* **四阶段伤害计算管线（DamagePipeline）**：加算基础伤害 -> 攻方状态（易伤/力量）修正 -> 防方格挡吸收 -> 穿透生命真实伤害。
* **Mulberry32 可重现伪随机数生成器（SeededRandom）**：全流程种子可控，支持洗牌、掉落、地图生成完全复现。
* **全生命周期事件总线（EventBus）**：支持遗物与卡牌精准监听 `ON_TURN_START`、`ON_CARD_PLAYED`、`ON_ATTACKED` 等十余种核心钩子。

### 3. 四幕战役与 15 层 DAG 战役地图
* **第一幕**：黄巾妖氛 · 巨鹿原野
* **第二幕**：虎牢凶关 · 焚城烽烟
* **第三幕**：赤壁业火 · 锁链冥河
* **第四幕**：建安魔障 · 九鼎残墟（终局之战）
* **战役节点**：前哨战、猛将营（精英）、奇遇事件、西域行商、大军营帐（调息/锻造）、军资宝库、守关大将。

### 4. 商业级三国国风视觉与动作打击系统
* **纯正古风矢量图标（Zero Emoji）**：全界面告别 Emoji，采用五铢方孔铜钱、血魄玉璧、战役舆图卷轴、调兵虎符、武技战令等独家矢量图标。
* **2D 战立立绘与动态打击动作**：
  * **战立与阴影**：大型战姿立绘搭配透视地面接触呼吸阴影；
  * **冲刺斩击**：出牌爆冲冲刺 140px，刀光残影拖尾与震屏；
  * **受击硬直**：受击高对比度白红爆闪、后仰爆退硬直与墨滴飞溅；
  * **御甲蓄气**：获得格挡时周身凝结流光护盾与气流护体。
* **Web Audio 原生合成音响**：无外部依赖的动态高保真音效系统，实时合成金属刀剑碰撞、重击震音、法术聚气、雷鸣啸聚与按键触感。

## 🚀 快速启动

### 运行环境
* Node.js 18+
* 现代浏览器（Chrome、Edge、Firefox、Safari）

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
```
启动后在浏览器打开：`http://localhost:5173/`

### 生产环境打包
```bash
npm run build
```
构建产物输出于 `dist/` 目录。

## 📂 目录结构

```text
├── data/                    # 静态数值与配置数据
│   ├── cards/              # 各武将卡牌池（关羽/诸葛亮/甘宁）
│   ├── enemies/            # 第 1 至第 4 幕怪物与首领数据
│   ├── relics/             # 战役稀世兵符遗物池
│   └── events/             # 奇遇事件分支选项
├── public/assets/           # 国风水墨场景、武将立绘与特技图
├── src/
│   ├── audio/              # Web Audio 纯代码合成音效引擎
│   ├── battle/             # 战斗实体、牌库管理与状态机
│   ├── core/               # 动作队列、伤害管线、事件总线、随机数种子
│   ├── map/                # 15层 DAG  procedural 地图生成器与进度存档
│   ├── story/              # 各幕史诗背景与剧情对白
│   ├── ui/                 # 交互界面、贝塞尔拖拽瞄准线、纯矢量图标集
│   ├── vfx/                # Canvas 粒子水墨斩击特效与立绘动效
│   ├── main.ts             # 游戏入口主文件
│   └── style.css           # 纯手写古风暗墨游戏级样式表
├── package.json
├── tsconfig.json
└── README.md
```
